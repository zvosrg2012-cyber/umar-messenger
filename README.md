# Umar Messenger

Первый UI-прототип.

## Design direction
- Чёрный фон + яркий оранжевый акцент.
- Ромбическая/угловатая геометрия вместо стандартных rounded corners.
- Главный экран: бренд, поиск, список чатов и нижняя навигация.
- Без тяжёлых градиентов и стеклянных карточек.
