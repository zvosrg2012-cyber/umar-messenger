# Umar Messenger

Production-ready front-end foundation for a social messenger interface.

## Стек

- HTML5 — семантическая структура и SEO-метаданные.
- CSS3 — адаптивная сетка, LOWPOLY-геометрия, accessibility states и reduced motion.
- Vanilla JavaScript — состояние интерфейса, чаты, поиск, фильтры, отправка сообщений, темы и локальное хранение.
- Без внешних UI-фреймворков и зависимостей.

## Структура проекта

```
umar-messenger/
```

## Интерфейс

1. **Sidebar** — бренд, поиск, фильтры, список диалогов и профиль.
2. **Conversation** — шапка диалога, сообщения и composer.
3. **Details panel** — дополнительная информация о текущем чате на широких экранах.
4. **New chat modal** — создание нового диалога без browser prompt.
5. **Responsive mobile view** — список и переписка работают как отдельные экраны.

## Логика

Состояние хранится в `localStorage` и изолировано в объекте приложения. Это позволяет позже заменить слой хранения на REST/WebSocket API без переработки визуального слоя.

Точки интеграции с сервером:

- загрузка списка диалогов;
- получение истории сообщений;
- отправка сообщения;
- read/unread;
- presence;
- вложения;
- авторизация и профиль.

## Сборка

Проект статический: отдельная сборка не требуется.

Локально:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

Для GitHub Pages используется workflow в `.github/workflows/pages.yml`.

## UX и accessibility

- клавиатурная навигация по чатам;
- `aria-label`, `aria-live` и семантические элементы;
- видимые focus states;
- поддержка `prefers-reduced-motion`;
- мобильная навигация;
- отсутствие зависимости от hover для ключевых действий.

## Визуальная система

Основной цвет: **#f58631**.

LOWPOLY применяется к логотипу, аватарам, кнопкам, полям и сообщениям через срезанные углы. Основная сетка остаётся строгой и геометрически выровненной, чтобы интерфейс выглядел как продукт, а не декоративный макет.
