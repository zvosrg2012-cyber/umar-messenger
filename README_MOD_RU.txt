WRECKBOX 1.6 — MOD «CHAOS TOOLS»

Что изменено:
- Добавлены команды в существующую игровую консоль: night, gravity, quake, tornado, blackhole, lightning, clear.
- Добавлены русские псевдонимы: ночь, гравитация, землетрясение, торнадо, дыра, молния, очистить.
- help теперь выводит список команд мода.
- Остальные исходные игровые файлы оставлены без намеренного изменения.

КАК ЗАПУСТИТЬ:
1. Распакуй архив в отдельную папку.
2. Открой index.html в браузере (лучше Chrome или Edge).
3. Запусти игру и открой встроенную консоль читов — ту же, где работают turbo/tsar/rain.
4. Введи команду и нажми Enter.

Примеры:
  help         список команд
  night        переключить день/ночь
  gravity      сменить гравитацию по кругу
  quake        землетрясение
  tornado      создать торнадо возле камеры
  blackhole    создать чёрную дыру возле камеры
  lightning    вызвать молнию возле камеры
  clear        очистить обломки

ВАЖНО:
- Это модифицированная копия HTML/JS, оригинальный Wreckbox.exe не меняется.
- Перед запуском сохраняй оригинальные файлы. Некоторые эффекты могут нагружать игру.
- Команды вызывают уже имеющиеся функции игры; никаких сетевых функций мод не добавляет.
- Если браузер ограничивает какие-то возможности, запускай игру штатным способом и перенеси изменения game.js/встроенного скрипта в её ресурсную папку.
